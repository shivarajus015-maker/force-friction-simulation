# force-friction-simulation
n interactive  Science simulation game for Force &amp; Friction (ಬಲ ಮತ್ತು ಘರ್ಷಣೆ) built with pure HTML, CSS, and JavaScript. Pull a virtual rubber band to launch a toy car across Paper, Cloth, Sandpaper, and Carpet surfaces, compare force vs. friction in a live data log, and unlock a bilingual English-Kannada mini-quiz!
